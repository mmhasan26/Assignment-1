 ## What happens during TypeScript compilation?

 Ans: The compiler reads your TypeScript code and checks whether its syntax is valid. Then The compiler checks the correct data types. After that The compiler removes TypeScript-specific syntax, including: Type annotations,Interfaces,Type aliases,Type declarations.After transformation, the compiler generates JavaScript files.



 ##  What is tsconfig.json?
tsconfig.json is the configuration file for a TypeScript project. It tells the TypeScript compiler how to compile our project.
Instead of writing compilation settings every time, We have to configure the file once in tsconfig.json.
